## Building the API reference

The reference is generated by [Doxygen](https://www.doxygen.nl/). CMake drives
it through the `QLIB_BUILD_DOCS` option:

```bash
cmake -S . -B build -DQLIB_BUILD_DOCS=ON
cmake --build build --target docs
```

The output lands in `docs/html/index.html`; open it with a browser. The
generated `docs/html/` and `docs/latex/` trees are not tracked by git.

If you would rather run Doxygen by hand, fill in the placeholders in
`Doxyfile.in` yourself and point `doxygen` at the result:

```bash
cd docs
sed -e 's|@PROJECT_SOURCE_DIR@|..|g' \
    -e 's|@PROJECT_BINARY_DIR@|..|g' \
    -e 's|@PROJECT_VERSION@|0.1.0|g' \
    -e 's|@PROJECT_NAME@|qlib|g' \
    Doxyfile.in > Doxyfile
doxygen Doxyfile
```

## Conventions used here

- Code blocks are compilable as written unless a snippet is explicitly marked
  as a fragment.
- `NULL` passed where a `const ql_allocator_t*` is expected always means "use
  the default allocator".
- Every function that returns `ql_ret_t` returns `QL_OK` (0) on success, so
  `if (rc != QL_OK)` is the correct check.
